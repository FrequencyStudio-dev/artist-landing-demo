# Artist Landing Demo

Demo de landing page para músicos y bandas, desarrollada por **Frequency Studio**.

El proyecto representa una solución digital independiente y más accesible que un sitio web completo de artista. Está pensada para presentar a un músico o banda, destacar un lanzamiento, mostrar una selección de trabajos y facilitar el contacto y la contratación.

## Demo

**Artista ficticia:** Lucía Varela
**Género:** Pop · Electrónica
**Ubicación:** Montevideo, Uruguay

## Características

* Hero con presentación del artista y llamada a la acción
* Presentación del artista
* Lanzamiento destacado
* Selección de trabajos musicales
* Próximas fechas en vivo
* Información de contacto y contratación
* Diseño responsive
* Navegación por secciones
* Estética editorial y contemporánea

## Desarrollo

Instalar las dependencias:

```bash
npm install
```

Ejecutar el servidor de desarrollo:

```bash
npm run dev
```

Abrir http://localhost:3000 en el navegador.

## Propósito

Este proyecto forma parte del catálogo de soluciones demostrables de **Frequency Studio**, orientado a crear soluciones digitales para artistas y proyectos creativos.
